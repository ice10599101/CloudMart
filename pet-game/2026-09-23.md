## v9：多视图重生成 —— 外观贴近概念图 + 眨眼成功（最终交付）

**用户反馈**：概念图可以，但生成的 3D 与概念图长得太不一样、有点丑。
**原因（4 条，都有据）**：图生 3D 的本质是「从一张图猜一个立体物」——
① 只有 3/4 单视图，另外 240°（后脑勺/侧面/底下）全靠脑补，脑袋宽度猜窄了；
② 贴图是**重画**不是复制，眼睛形状/针织纹/绒毛感都被重新诠释，且光照被烘进反照率；
③ 融合网格会把小细节揉掉（针织纹变绳状、围巾垂坠消失、铃铛变小）；
④ 概念图的「蓬松」是渲染质感不是几何，图生 3D 还原不了。

**解法：`--multi-view` 多视图输入**（官方 3D 生成的标准能力）。

### 多视图生成
- 用 ImageGen **图生图**（input_fidelity: high、以概念图为参照）生成 正视图 / 右侧视 / 背视图
- **⚠️ 多视图 JSON 的合法 ViewType**：`back, left, right, top, bottom, left_front, right_front`
  （"front"/"side" 不合法，API 会报 InvalidParameterValue.InvalidViewType —— API 报错信息里会列出合法值）
- **⚠️ 多视图的 `ViewImageUrl` 必须是公网 URL**，且 **签名 URL 20 分钟就过期** ——
  第一次提交报「文件下载失败」，就是因为注册到提交隔了 20 分钟。必须**上传完立刻提交**。
- **⚠️ 上传用 urllib 而不是 curl**：长签名 URL 在 bash 里 `curl` 会连不上（000/56）。

### 结果（55 点数，4 分钟）
**明显更贴近概念图**：头圆了、大眼带深色瞳孔与高光、围巾有垂坠、铃铛在、尾巴蓬松离体。
生产化：**13,220 面 / 2.46MB / metallic 0 / extensionsUsed None**。

### 绑骨 + 眼皮 + 三条动画（`rig_cat_v2.py`）
- 重测解剖：身高 0.826 · 双眼**对称** (0.143,-0.001,0.455) / (-0.197,-0.019,0.455)（z 完全一致！）·
  耳根/耳尖实测 · 尾巴 S 形路径 (0.28,0.30,0.04)→(0.35,0.28,0.49)
- **眼皮成功**：两只眼球都能用最小二乘拟合（201 / 265 点，比 v1 的 33/137 可靠得多）
- **⚠️ 兜底必须只给身体骨骼**：否则「半径全不覆盖时兜底给最近骨骼」会把脸和胡须的远端顶点
  吸到眼皮骨上（实测 EyelidR 白拿 3980 顶点，眨眼会把脸拖走）
- 15 根形变骨全部拿到顶点、无空组
