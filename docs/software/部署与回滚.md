# 小答软件模块 部署与回滚记录

> 2026-10-16 · 适用 mall-software（9026）/ mall-admin（9020，软件管理面）。

## 1. 组件与依赖

| 组件 | 端口 | 说明 |
|---|---|---|
| mall-software | 9026 | 软件模块服务（公开面 /software/**、作者面、内部 /internal/**） |
| mall-admin | 9020 | 管理后台（软件管理代理 /api/admin/software/** 经网关 8090） |
| MySQL | 8306 | mall_software 库，Flyway V1–V8 版本化迁移 |
| Redis | 8379 | 限流/榜单缓存/分布式锁 |
| Nacos | 8848 | 配置中心（mall-software.yml + shared-runtime.yml） |
| RocketMQ | — | 通知/擦除事件（Outbox 模式投递） |

## 2. 部署步骤

1. `git pull` 后构建：`./mvnw -pl mall-admin,mall-software -am package -DskipTests`
2. 部署 jar 并重启服务（Flyway 启动时自动执行未应用的迁移，当前最新 **V8**）
3. 确认健康：`GET :9026/actuator/health` → `{"status":"UP"}`
4. 确认迁移：`SELECT version, success FROM mall_software.flyway_schema_history
   ORDER BY installed_rank DESC LIMIT 1;` → 8 / 1
5. 确认指标：`GET :9026/actuator/prometheus` 含 `software_review_pending` 等

## 3. 灰度开关（Nacos mall-software.yml，热更新生效）

```yaml
software:
  enabled: true                  # 总开关：false 时公共读写 403 SOFTWARE_DISABLED，
                                 # 作者受控入口（编辑器/草稿/偏好）与后台处置保留
  publish-enabled: true          # 投稿：false 时提交审核 403
  resolve-enabled: true          # 获取链接：false 时 403 SOFTWARE_RESOLVE_DISABLED（A30）
  subscription-enabled: true     # P1 订阅新增+广播调度器
  rankings-enabled: true         # P1 榜单
  # 日级限流（0=不限）：publish-submissions-per-user-day / feedback-per-user-day /
  # report-per-user-day；分钟级：comment-per-user-minute / resolve-per-user-minute
```

> ⚠️ 编辑该文件必须整段合法 YAML（曾因转义问题写入损坏内容导致刷新静默失败）。
> 验收脚本 `scripts/e2e/e07-switches.sh` / `e08-acceptance.sh` 会自动改写并还原。

## 4. Prometheus 接入

服务器上 Prometheus 的 prometheus.yml（**与仓库 docker/ 目录不同源**）需包含：

```yaml
  - job_name: 'mall-software'
    metrics_path: '/actuator/prometheus'
    static_configs:
      - targets: ['host.docker.internal:9026']
  - job_name: 'mall-admin'
    metrics_path: '/actuator/prometheus'
    static_configs:
      - targets: ['host.docker.internal:9020']
```

改完执行 `docker exec cloudmart-prometheus kill -HUP 1` 热加载（或重启容器）。
Grafana 面板 JSON 在仓库 `docker/grafana/dashboards/software.json`。

## 5. 回滚

### 5.1 应用回滚
- 常规：回退到上一版本 jar 重启即可。当前无未完成的破坏性迁移。
- **V8 迁移（2026-10-16）**：将 `software_link_feedback` 唯一键从
  `(reporter_id,software_id,source_key,source_fingerprint)` 换为含 `status` 的
  五列键。旧版应用兼容新键（只读不受影响）；如需回滚 DDL：

```sql
ALTER TABLE mall_software.software_link_feedback
  DROP KEY uk_feedback_reporter_fp_status,
  ADD UNIQUE KEY uk_feedback_reporter_fingerprint
      (reporter_id, software_id, source_key, source_fingerprint);
-- 前置检查：同指纹多状态行存在时先归并，否则加键失败
SELECT reporter_id, software_id, source_key, source_fingerprint, COUNT(DISTINCT status) c
FROM mall_software.software_link_feedback
GROUP BY 1,2,3,4 HAVING c > 1;
```

- Flyway 原则：**迁移提交后禁止修改**；修复一律新增 V9+。

### 5.2 开关应急
- 软件模块整体异常：Nacos `software.enabled: false`（公共面立即 403，后台与
  作者草稿不受影响）
- 仅获取链接异常：`resolve-enabled: false`
- 仅榜单/订阅异常：对应独立开关 false

### 5.3 数据修复
- 演示/验收数据统一带可识别指纹（名称 `E08 验收工具`、评论 `LOADTEST%`），
  `scripts/performance/software-load.py` 的 cleanup() 为权威清理 SQL。

## 6. 已知运维注意

1. mall_notification 通知表名为 **notifications**（复数）
2. 9026 的 `/actuator/prometheus` 已匿名放行（抓取用）；`/actuator/metrics|env`
   仍锁定；`/actuator/health` 匿名
3. 用户 JWT 约 25 分钟过期（认证层既有行为）
4. Git Bash 下向 Nacos 写多行 YAML：禁止在嵌入脚本里直接用 `\n`（MSYS 会改写
   为 `/n` 产出损坏 YAML、Spring 刷新静默拒绝但**重启会翻车**）——用 chr(10) 或
   落盘文件再 urlencode
5. e2e/压测脚本会临时改写 Nacos 配置（限流/开关），均带退出还原；如脚本中途
   kill，对照本文 §3 手工核对终态
