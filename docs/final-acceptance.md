## 遗留风险（上线前必读）

1. **安全收口未做（Critical）**：Redis 8379 无密码、MySQL 8306 root 弱口令、服务端口 9001-9030 公网可达。本次验收曾实际利用这些通道（自助注册、直连查库）。安全组收口+Redis requirepass+MySQL 强口令为上线前置条件。
2. **T07 真实渠道**：模拟渠道逻辑已覆盖，沙箱回归未做。
3. **IT job**：pet 钱包 IT 失败归并行会话；mall-wish IT 本地外部实例模式 196/196 绿。
4. **性能实测**：seed 数据集已灌（orders 5000/wish 3000），P95 目标未压测（缺压测工具链）。
